# ZM Hybrid Store — AliExpress One-Click Import

## Store UI
The homepage has been redesigned to closely follow the supplied marketplace-style reference: premium purple theme, search header, category ribbon, featured deals, brand strip, new arrivals and trust strip.

## One-click importer
This build includes `chrome-extension/`.
1. Chrome → Extensions → Developer mode.
2. Load unpacked → choose `chrome-extension/`.
3. Open an AliExpress product page.
4. Click the ZM Importer extension.
5. Click **Import to ZM Store**.
6. ZM Admin opens the AliExpress Importer with detected title, description, images, SKU and price.
7. Review target market, markup and affiliate commission, then Create product draft.

The importer does not automatically publish products. Review is required before publishing.
